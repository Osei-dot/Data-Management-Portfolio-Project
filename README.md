# Data-Management-Portfolio-Project
CitiBike Data Analysis

This project is part of my Data Engineering Journey, showcasing my ability to collect, clean, organize, and analyze data in a structured and manner. 
It demonstrates best practices in data wrangling, database design, querying, and reporting. 

# The project emphasizes:

1. Combining data from multiple sourses using glob library

2. Cleaning and transforming raw datasets.

3 Managing relational databases with PostgreSQL.

# Tools & Technologies

Programming: Python (Pandas, NumPy, SQLAlchemy)

Databases: PostgreSQL 

Other: Jupyter Notebook, Excel

# Project objectives:
Use Jupyter notebooks and pandas to explore, clean, and transform datasets
Design and implement a relational PostgreSQL database
Use SQL to develop analytics-ready database views

# Prerequisites:
Pandas,
SQL,
Knowledge of data cleaning.
